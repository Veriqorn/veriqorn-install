# Veriqorn Community v0.2.7

## Highlights

- Community and Enterprise now follow one release train: `v0.2.7`.
- The installer is prepared for signed, edition-specific update channels.
- Enterprise updates verify image signatures and retain immutable image digests
  after a successful update.

## Upgrade

Use the normal in-product update flow, or set `PLATFORM_VERSION=v0.2.7` and
run Docker Compose pull/up according to the installation guide. Community users
continue to receive only Community images from the public update channel.
