# Veriqorn Community v0.2.8

## Highlights

- Offline license activation now accepts the schema-v3 Veriqorn product
  license envelope issued by the current license operations tool.
- Activation requests exported from the AI settings use the schema-v3 product
  installation identity.

## Upgrade

Set `PLATFORM_VERSION=v0.2.8` and run Docker Compose pull/up according to the
installation guide. Existing PostgreSQL and MinIO volumes are retained during
the upgrade.
